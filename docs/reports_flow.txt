Reports Flow Documentation

1. Overview:
   The Reports page allows the Admin to generate new society financial reports (Monthly or Yearly) in PDF or CSV format, and to access previously generated reports for quick viewing and downloading.

2. Access Past Generated Reports:
   - Admin navigates to the Reports section.
   - The UI lists past generated reports fetched from the database.
   - Details displayed for each report include:
     * Report Date
     * Format (PDF / CSV)
     * Period (Monthly / Yearly)
     * Action to View / Download the document.

3. Generation of New Report:
   - Input: Admin selects the desired Format (PDF or CSV) and Period (Monthly or Yearly with the specific month/year).
   - Action: Admin triggers the report generation.
   - Backend Processing: 
     * Backend aggregates data to dynamically generate the report.
     * The report includes important financial metrics:
       - Total collection summary
       - Pending payments list
       - Payment-mode breakdown
   - DB Action: Backend saves the newly generated report details in the database so it can be accessed later in the "Past Generated Reports" list.
   - Return: Backend returns the generated report to the Admin for immediate download or viewing.
